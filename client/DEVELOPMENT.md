# Frontend Doble A

React + JavaScript + Vite + React Router. Ejecutar desde la raíz `npm run dev` para iniciar frontend y backend juntos. Instrucciones completas en [README.md](../README.md).

Organización: components (UI), pages (pantallas), layouts (tienda/panel), context y hooks (sesión y datos), services (cliente HTTP), routes (protección), utils (formato). Estilos separados en styles.css, pages.css y responsive.css.

El frontend no recibe claves de Supabase ni decide precios finales, stock o permisos administrativos. Todas las operaciones de negocio pasan por Express.
